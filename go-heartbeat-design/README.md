## 核心发现

### E1：Go 1.23 Timer/Ticker GC 改进受 go.mod 版本控制

**发现**：Go 1.23 确实修复了 Timer/Ticker 的 GC 问题——但只在 go.mod 声明 `go 1.23` 及以上时生效。go.mod 写 `go 1.22` 及以下的项目，即使运行在 Go 1.26 上，仍然使用旧 GC 行为（Timer 不被回收）。

| go.mod 版本 | Go 1.22 | Go 1.23 | Go 1.24-1.26 |
|:-----------:|:-------:|:-------:|:------------:|
| go 1.21/1.22 | 150K objects（泄漏） | 150K（泄漏） | 150K（泄漏） |
| go 1.23 | N/A | **25（回收）** | **14-27（回收）** |

**机制**：Go 的 GODEBUG 兼容机制——go.mod 版本决定 GODEBUG `asynctimerchan` 的默认值。`go 1.22` → asynctimerchan=1（旧行为）；`go 1.23` → asynctimerchan=0（新行为）。
