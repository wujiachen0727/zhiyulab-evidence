# E1 幂等键防重复实验

## 运行环境

- Go 1.26.2 (darwin/arm64)
- 无外部依赖，纯标准库

## 运行方式

```bash
cd e1-idempotency-key
go run main.go
```

## 实验设计

模拟客户端携带 Idempotency-Key 提交创建支付单请求：

| 组 | 说明 | 预期 |
|----|------|------|
| 对照组 A | 无幂等键，同一请求重发 100 次 | 产生 100 个订单（99 笔重复入账） |
| 实验组 B | 有幂等键表（key 唯一约束） | 只产生 1 个订单，后续返回首次结果 |

## 结果摘要

```
对照组A（无幂等键）: 重发 100 次 → 订单数 100（重复入账 99 笔）
实验组B（有幂等键）: 重发 100 次 → 订单数 1（重复入账 0 笔）
第 101 次重试同 key 同参数: 返回订单 order-1, 新建=false, 状态=REPLAY
同 key 不同金额: PARAM_MISMATCH: 同 key 不同参数，服务端拒绝
```

## 结论

- 幂等键（唯一约束 + 首次结果缓存）100% 拦截重复创建
- 同 key 不同参数必须拒绝（防止客户端误用 key）
- 完整输出见 `../../output/e1-idempotency-key/result.txt`
