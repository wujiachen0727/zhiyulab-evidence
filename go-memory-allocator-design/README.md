## 关键数据速查

| 实验 | 核心发现 | 数据 |
|------|---------|------|
| E1 | 无缓存→有缓存→大小类，延迟逐步下降 | v0 1.04s → v1 0.78s → v2 0.57s（混合模式） |
| E1b | **纯分配（低缓存命中）时缓存反而拖累** | v0 0.78s < v1 0.92s（纯分配模式） |
| E2 | 跨 size class 边界有可测差异，但非均匀 | 32B 263ns → 33B 437ns（+66%）；128B 779ns → 129B 790ns（+1%） |
| E3 | tiny allocator 大幅提升小对象内存效率 | 4B 74ns/416B vs 32B 293ns/3200B |
| E4 | 分配本身被 GC 成本掩盖 | 短生命周期 12.2ms vs 长生命周期 8.5ms（同分配量） |
| E5 | 大小类非均匀间隔，waste 控制 | 68 档，8B 类 max waste 87.5%，大档 <15% |

## 证伪实验记录
