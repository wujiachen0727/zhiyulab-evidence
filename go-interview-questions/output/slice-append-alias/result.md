# slice-append-alias 运行结果

**对应题目**：二、slice 和数组
**目的**：找出 `append` 复用底层数组的精确条件，以及子切片的容量到底是多少
**运行方式**：`cd code/slice-append-alias && go run .`
**原始输出**：`result.txt`（stdout）

## 关键输出

```
a                  len=3 cap=4 值=[1 2 3]
head = a[:2]       len=2 cap=4 值=[1 2]
head 追加 99 后     len=3 cap=4 值=[1 2 99]
a 被改了            len=3 cap=4 值=[1 2 99]

b[:2]              len=2 但 cap=3（不是 2）
b[:2] 追加 99 后     len=3 cap=3 值=[1 2 99]
b 还是被改了         len=3 cap=3 值=[1 2 99]

c[:2:2]       len=2 且 cap=2（三下标把容量也切了）
c 这次没变      len=3 cap=3 值=[1 2 3]

e = append(d, 10)     len=4 cap=4 值=[1 2 3 20]
f = append(d, 20)     len=4 cap=4 值=[1 2 3 20]
改 e[0] = 777，再看 f：
f                     len=4 cap=4 值=[777 2 3 20]
```

## 结论

`append` 是否复用底层数组，取决于追加后的总长度有没有超过容量。这里最关键的一点是：**子切片的容量继承到原数组的末尾**，`b[:2]` 的 cap 是 3 而不是 2，所以看起来"越界"的追加仍然写进了共享内存。要让子切片彻底独立，得用三下标 `c[:2:2]` 把容量一起切掉。

容量够用时连做两次 append 会互相覆盖，第二次把第一次盖掉，两块切片指向同一段内存。
